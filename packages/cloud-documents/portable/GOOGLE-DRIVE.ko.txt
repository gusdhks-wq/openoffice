Google Drive 중심 연결 — 최초 로그인 설정

이 방식은 휴대폰과 Google이 직접 통신합니다.
Google 문서에 저장한 뒤에는 PC·Start.cmd·Mobile-connect.cmd·TTT 없이도
휴대폰에서 문서를 받고, ChatGPT의 Google Drive 도구로 같은 문서를 수정할 수 있습니다.
앱 안에서 AI가 자동 실행되는 기능은 아닙니다.

현재 빌드에는 본인 Google Cloud 프로젝트나 실제 로그인 설정이 없습니다.
아래 설정은 본인 계정의 Google Cloud Console에서 한 번 진행합니다.
비밀번호, 클라이언트 비밀키, 로그인 토큰을 채팅으로 보내지 마세요.

Android 설정:
1. https://console.cloud.google.com/ 에서 프로젝트를 만듭니다.
2. API 및 서비스 > 라이브러리에서 Google Drive API와 Google Docs API를 모두 사용 설정합니다.
3. Google Auth Platform에서 앱 이름·지원 이메일을 설정합니다.
   대상은 개인 테스트에 맞게 설정하고, 테스트 사용자에 본인 Google 계정을 추가합니다.
   데이터 액세스 범위는 https://www.googleapis.com/auth/drive.file 입니다.
4. 클라이언트 > 클라이언트 만들기에서 OAuth 클라이언트 유형 Android를 선택합니다.
   패키지: com.ieumoffice.mobile.prototype
   SHA-1: 이 APK와 함께 제공된 GOOGLE-OAUTH-SETUP.ko.txt 맨 아래 값을 사용합니다.
   APK마다 디버그 서명이 달라질 수 있습니다. 새 APK는 해당 SHA-1 등록을 확인하세요.
5. 앱에서 'Google 문서 동기화'를 선택하고 '드라이브 연결'을 누릅니다.
   ChatGPT의 Google Drive에 연결한 것과 같은 계정으로 승인합니다.
6. 기기 문서를 선택하고 '이 문서 동기화'를 누릅니다.
   처음에는 새 Google 문서를 만들며, 다음부터 같은 Google 문서 ID를 유지합니다.
7. 'Google 문서 열기'에서 주소를 복사해 ChatGPT에 주면 파일을 정확히 지정할 수 있습니다.
   수정 요청은 Google Drive 플러그인을 사용하세요. TTT는 PC 문서 서버용입니다.

앱이 전면에 열려 있고 연결돼 있으면, 연결된 활성 문서의 변경을 약 15초마다 확인합니다.
로컬 수정은 저장과 한글 조합이 끝난 뒤 약 1.5초 후 전송합니다.
오프라인에서는 기기 초안을 보존합니다. 앱을 닫았다 열면 드라이브에 다시 연결하세요.
접근 토큰은 메모리에만 있으며, 계정 비밀번호·새로고침 토큰을 저장하지 않습니다.
Android에서는 Google Play 서비스가 필요합니다. 실계정 로그인과 기기 종료 복구는 별도 확인이 필요합니다.

지원 범위와 복구:
- 현재는 표·복잡한 서식·이미지·여러 탭이 없는 텍스트 Google 문서만 수정합니다.
  Markdown은 Google 문서 안에 원문 텍스트로 들어갑니다. Office 서식을 변환하지 않습니다.
- 기존 '이전 방식: 파일별 백업' 파일은 수정하거나 지우지 않습니다.
- 양쪽에서 고쳤으면 초안을 남기고 충돌을 알립니다. 드라이브 수정본은 별도로 열 수 있습니다.
- 생성 응답이 끊기면 같은 작업의 파일을 찾아 확인하며, 무작정 새 파일을 다시 만들지 않습니다.
  끝내 확인할 수 없을 때 '전송 대기 취소'는 기기 문서만 대기 해제합니다.
  이미 생성된 Drive 파일은 남습니다. 새 동기화를 하기 전에 드라이브 목록을 확인하세요.
- 기존 앱을 삭제하면 기기에만 있던 문서가 지워집니다. APK 업데이트가 거부되면
  기존 앱을 바로 삭제하지 말고, 먼저 내보내거나 기존 서버에 저장하세요.

웹 설정 (선택):
- 같은 프로젝트에서 웹 애플리케이션 OAuth 클라이언트를 만듭니다.
- JavaScript 원본에 앱의 정확한 주소를 등록합니다. 개발용 예: http://localhost:5181
- 앱의 구글 로그인 설정을 펼쳐 공개 클라이언트 ID를 입력·저장합니다.
  비밀키는 입력하지 않습니다. 공개 ID만 이 기기에 저장됩니다.
- 임시 trycloudflare 주소는 바뀔 때마다 원본 등록이 달라집니다.
  PC 없이 휴대폰에서 쓰려면 Android 앱을 사용하거나 별도 고정 웹 호스팅이 필요합니다.

실제 계정 연결 완료 여부는 로그인 후 앱→Drive 저장과 Drive→앱 반영을 모두 확인해야 합니다.
코드·모의 테스트·APK 컴파일만으로 실제 Google 계정 연결을 완료했다고 말하지 않습니다.
