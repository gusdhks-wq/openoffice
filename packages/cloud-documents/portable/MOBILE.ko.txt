PC·휴대폰 문서 연결 / ChatGPT 문서 도구 연결 — 테스트용

처음에:
- 추가 파일은 기존 Start.cmd가 있는 폴더에 압축 해제합니다.
- 기존 Start.cmd 실행 창은 켜 둡니다. 문서나 연결키를 옮기거나 새로 만들지 않습니다.
- Mobile-connect.cmd를 더블클릭합니다.
- Cloudflare가 PC 문서 서버에 연결되는 임시 HTTPS 주소를 발급합니다.
  문서는 연결키 또는 승인된 OAuth 토큰이 있어야 접근할 수 있습니다.
  Cloudflare가 TLS 연결을 중계하므로 공유할 문서를 본인이 판단해 선택하세요.
- 이 창과 PC를 끄면 원격 연결은 멈추며, 재실행하면 주소가 바뀝니다.
  영구 서버나 정식 플러그인 배포용 주소가 아닙니다.

휴대폰 연결 (새 화면):
1. 휴대폰 브라우저에서 PC 창의 HTTPS 주소를 엽니다. 서버 주소는 자동으로 채워집니다.
   새 안드로이드 앱에서도 '외부 Codex 문서 연결'을 펼쳐 같은 기능을 사용합니다.
2. 서버 주소에는 PC 창의 https://...trycloudflare.com 주소를 입력합니다.
   휴대폰의 127.0.0.1 주소는 PC 주소가 아닙니다.
3. 연결 방법에서 '휴대폰 연결 코드 (8자리)'를 선택합니다.
   PC 창의 Phone pairing code를 입력합니다. ChatGPT 승인 코드와는 다릅니다.
   코드는 3분 동안 한 번만 사용할 수 있고, 잘못 입력할 수 있는 횟수는 5번입니다.
   새 코드가 필요하면 PC 창에 P를 입력하고 Enter를 누릅니다.
   새 코드 발급은 기존 ChatGPT 연결이나 다른 휴대폰 연결을 끊지 않습니다.
4. 연결 후 '서버 문서 새로고침'을 누르고 PC에서 올린 문서를 선택합니다.
   글을 바꾸고 문서 동기화를 누르면 같은 서버에 저장됩니다.
   연결된 문서는 앱이 열린 동안 변경을 확인합니다. OS 백그라운드 실행은 없습니다.
5. 새 앱은 마지막으로 연결된 주소만 기억하며, 키나 코드를 저장하지 않습니다.
   세션은 앱이 실행되는 동안만 메모리에 보관되며 서버에서는 최대 8시간 유효합니다.
   '서버 연결 해제'는 해당 휴대폰 세션을 취소합니다.
6. 주소가 바뀌었으면 새 주소에 연결하고, 같은 서버로 확인된 문서는
   '이 문서를 현재 주소에 다시 연결'을 누릅니다. 초안과 충돌 검사는 유지됩니다.
   브라우저 초안은 원래 주소에 묶여 있으므로 주소를 바꾸기 전에 서버 저장 또는 내보내기를 하세요.

기존 APK는 그대로 사용할 수 있습니다. 연결 방법 선택이 없으면 이전처럼 OWNER 키로
연결하세요. 새 화면은 휴대폰 브라우저에서 바로 사용할 수 있습니다.
APK 업데이트가 서명 문제로 설치되지 않아도 기존 앱을 지우지 마세요.
서버에 올리지 않은 초안을 먼저 내보내거나 동기화한 뒤에만 앱 교체를 검토하세요.

ChatGPT 웹:
1. 플러그인 > + > 사용자 지정 MCP 서버 추가.
2. 서버 URL은 위 주소 뒤에 /mcp를 붙입니다.
3. 인증은 OAuth를 선택하고 선택 입력인 클라이언트 ID/비밀키는 비워 둡니다.
   동적 등록(DCR)은 자동으로 처리되며 별도 선택 항목이 없을 수 있습니다.
4. 연결 승인 화면이 열리면 PC Mobile-connect 창의 8자리 승인 코드를 입력합니다.
   이 화면에는 소유자 연결키나 ChatGPT 비밀번호를 입력하지 않습니다.
5. 생성된 플러그인을 설치한 뒤 새 Work 대화에서 @로 선택합니다.
   문서 목록을 읽어 보도록 요청합니다. 실제 도구 호출이 성공해야 연결 완료입니다.
   계정·워크스페이스의 쓰기 권한 제한이 있으면 수정 기능을 사용할 수 없습니다.

인증과 공유:
- 승인 코드는 3분 유효하고 잘못 입력할 수 있는 횟수가 제한됩니다.
- OAuth 토큰은 메모리에만 남습니다. 이 창을 종료하면 해당 연결은 무효화됩니다.
- 외부 도구는 공유 문서와 그 이전 버전만 읽고 수정할 수 있습니다.
- 문서 공유를 끄면 이후 도구 접근은 즉시 차단됩니다.
- 기존 방식의 PC·Android·ChatGPT 양방향 저장/조회는 사용자 환경에서 확인했습니다.
  새 코드 연결은 별도 확인이 필요합니다. 연결 실패 시 코드/키 대신 오류 문구만 공유하세요.
- OpenAI 모델 API를 호출하지 않으며 API 키를 받지 않습니다.
