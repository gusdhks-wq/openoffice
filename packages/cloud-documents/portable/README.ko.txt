윈도우 PC에서 실행하기 — 테스트용 휴대용 패키지

1. ZIP 전체를 본인 PC의 폴더에 압축 해제합니다.
2. Start.cmd를 더블클릭합니다. 브라우저가 열립니다.
   실행 중인 검은 창은 닫지 마세요. 창을 닫으면 문서 서버가 멈춥니다.
3. 문서를 만들거나 .md/.txt 파일을 가져올 수 있습니다.

PC 문서 서버에 연결하려면:
- Connection-settings.cmd를 열어 본인 PC에서 연결키를 확인합니다.
- 화면의 '외부 Codex 문서 연결'에 http://127.0.0.1:5182와
  GENOFFICE_CLOUD_OWNER_TOKEN 값을 입력합니다.
- '문서 동기화'를 누른 뒤, 외부 도구가 수정할 문서만 공유합니다.
- 외부 도구에는 /mcp 주소와 별도 GENOFFICE_CLOUD_AGENT_TOKEN을 사용합니다.

중요:
- .env.cloud.local 파일과 연결키를 채팅이나 GitHub에 올리지 마세요.
- PC 서버 문서는 .ieumoffice-cloud-data 폴더에 저장됩니다.
  백업은 서버를 정상 종료한 뒤 비공개 위치에 보관하세요.
- 이 패키지는 개발용 편집기입니다. .md/.txt만 편집합니다.
- Node 설치나 관리자 권한은 필요하지 않습니다. 인터넷에 공개되지 않습니다.
- PC를 끄면 서버 연결도 끊깁니다. 클라우드 Codex 자동 연결은 포함되지 않습니다.
- 윈도우 실기기 검증과 안드로이드 실기기 검증은 별도로 필요합니다.
- 백신이나 윈도우 보호 기능을 끄지 마세요. 코드 서명된 정식 설치본이 아닙니다.

휴대폰 APK는 별도 테스트용 앱이며 기본적으로 휴대폰 안에서 편집합니다.
PC 연결에는 Android USB 디버깅/포트 연결 또는 별도 HTTPS 연결이 필요합니다.
설치만으로 휴대폰과 PC 문서가 자동 연결되지는 않습니다.

시작 오류가 나면:
- 다른 실행 창이 있으면 먼저 Ctrl+C로 정상 종료합니다.
- Repair-and-start.cmd를 실행하면 종료된 프로세스의 남은 잠금만 복구합니다.
- 실행 중인 프로세스, 포트 충돌, 확인할 수 없는 잠금은 변경하지 않습니다.
- 문서나 연결키는 초기화하지 않습니다. 실패하면 화면의 오류 코드만 알려주세요.
- 사용을 마칠 때는 실행 창에서 Ctrl+C로 정상 종료하세요.
