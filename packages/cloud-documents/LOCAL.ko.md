# 내 PC에서 먼저 사용하기

서버를 빌리지 않고 PC에서 모바일 편집 화면과 문서 서버를 함께 실행합니다.
PC의 Codex CLI/IDE 등 외부 도구에 문서 연결 기능을 제공하며 OpenAI API를 호출하지 않습니다.
현재 데스크톱 프로그램의 모든 문서가 자동으로 이 저장소에 연결되는 기능은 아닙니다.
먼저 `.md`·`.txt` 문서를 가져와 사용합니다.

## 준비와 실행

Node.js 22.12 이상과 npm 10 이상이 필요합니다. 저장소의
`feat/mobile-offline-prototype` 브랜치를 내려받은 폴더에서 터미널을 엽니다.
아래 명령을 한 줄씩 실행합니다. Windows PowerShell에서도 같습니다.

```sh
npm ci --ignore-scripts
npm run build:cloud
npm run build:mobile
npm run start:local
```

이 실행 방법은 Electron이나 Android SDK를 설치하지 않습니다. 처음 설치·빌드에는 인터넷이 필요합니다.
다음 실행부터는 `npm run start:local`만 사용합니다. 코드를 업데이트하면 다시 빌드합니다.
브라우저에서 `http://127.0.0.1:5181`을 엽니다. 창을 닫거나 Ctrl+C를 누르면 서버가 멈춥니다.
PC를 끄면 동기화와 외부 문서 접근도 멈춥니다.

첫 실행은 저장소 루트에 `.env.cloud.local`이라는 비공개 연결키 파일을 생성합니다.
기존 파일은 덮어쓰지 않습니다. 파일의 `GENOFFICE_CLOUD_OWNER_TOKEN` 값을 본인 PC에서 확인하고,
편집 화면의 ‘외부 Codex 문서 연결’에 서버 주소 `http://127.0.0.1:5182`와 함께 입력합니다.
문서를 동기화하고 원하는 문서에만 외부 공유를 켭니다.
이 파일이나 키를 채팅·이슈·PR에 붙여 넣지 마세요. 키는 브라우저에 영구 저장되지 않아 재실행 시
입력이 필요합니다. Windows의 파일 접근 권한은 계정과 폴더의 ACL도 확인합니다.

## PC의 Codex와 연결

문서 도구 주소는 `http://127.0.0.1:5182/mcp`입니다. 외부 클라이언트에는 owner 키 대신
별도 `GENOFFICE_CLOUD_AGENT_TOKEN`을 사용합니다. 해당 프로그램이 제공하는 비밀값 전달 방식으로
환경변수를 설정합니다. 구독 로그인 파일을 읽거나 바꿀 필요가 없습니다.
[상위 안내](README.md#connect-codex-cli-app-or-ide-through-mcp)에 설정 예시가 있습니다.

연결한 클라이언트에서 문서 도구 목록이 표시되는지 확인한 뒤, 공유 문서를 읽고 수정하도록 요청합니다.
서버가 수정 사항을 저장하면 열린 모바일 편집 화면이 약 15초 주기로 확인합니다.
키를 연결한 것만으로 AI 작업이 자동 실행되지는 않습니다.

**클라우드 Codex는 PC의 `127.0.0.1`에 접근할 수 없습니다.** 이 로컬 설정만으로
ChatGPT/클라우드 Codex에 도구가 설치되거나 연결되지는 않습니다. 원격 사용은 이후 HTTPS 주소와
그 서비스가 지원하는 인증·도구 연결을 따로 구성해야 합니다.

## Android 휴대폰에서 USB로 확인하기

Android Platform Tools의 `adb`가 설치되어 있고, 본인 휴대폰에서 USB 디버깅을 허용한 경우에만
다음 방법을 사용할 수 있습니다. Google 로그인이나 APK 설치는 필요하지 않습니다.

```sh
adb devices
adb reverse tcp:5181 tcp:5181
adb reverse tcp:5182 tcp:5182
```

PC의 서버를 실행한 채 휴대폰 Chrome에서 `http://127.0.0.1:5181`을 엽니다.
문서 서버 주소도 `http://127.0.0.1:5182`로 입력합니다. USB 연결을 끊으면 PC 동기화가 중단됩니다.
확인이 끝나면 다음 두 연결을 제거하고 필요에 따라 USB 디버깅을 끕니다.

```sh
adb reverse --remove tcp:5181
adb reverse --remove tcp:5182
```

이 USB 방법은 안내를 준비한 상태이며 실제 휴대폰 검증은 남아 있습니다.
iPhone과 무선 접속에는 별도 HTTPS 설정이 필요합니다. PC의 사설 IP를 HTTP로 여는 방식은
이 앱의 연결 정책과 오프라인 저장 요구에 맞지 않습니다. 실행 도우미는 PC 내부에서만 접속을 받습니다.

## 문서 보관과 문제 해결

문서는 PC의 `.ieumoffice-cloud-data` 폴더에 남습니다. 연결키 파일과 이 폴더는 Git에서 제외됩니다.
문서 서버를 정상 종료한 뒤 두 항목을 비공개 위치에 백업합니다. 브라우저의 로컬 초안은 별도 저장이므로
중요한 문서는 내보내기도 해 둡니다. Google Drive 연동은 별도 선택 기능입니다.

5181·5182 포트가 사용 중이면 기존 프로그램을 확인합니다. 필요하면 실행 전
`GENOFFICE_LOCAL_WEB_PORT`와 `GENOFFICE_LOCAL_API_PORT` 환경변수로 서로 다른 포트를 지정하고,
브라우저·MCP 주소와 USB 연결에도 같은 포트를 사용합니다.
잠금 오류가 나면 같은 문서 폴더를 사용하는 서버가 이미 실행 중인지 먼저 확인합니다.
잠금 파일을 무조건 지우거나 저장소를 초기화하지 마세요.
