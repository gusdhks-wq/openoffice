# 윈도우·안드로이드 테스트 파일

2026-10-23 기준, [테스트 빌드](https://github.com/gusdhks-wq/openoffice/actions/runs/39963541968)의
윈도우와 안드로이드 작업이 모두 성공했습니다. GitHub 로그인 뒤 Artifacts에서 내려받습니다.
파일은 14일 보관되며, 이후에는 Mobile preview packages 워크플로를 다시 실행해야 합니다.
정식 릴리스나 스토어 배포는 하지 않았습니다.

1. 윈도우: `IeumOffice-Mobile-PC-Windows-x64-preview`를 받아 압축을 모두 풀고 `Start.cmd`를 더블클릭합니다.
   Node.js 설치나 빌드는 필요하지 않습니다. 브라우저가 열리며, 사용을 마치면 실행 창에서 Ctrl+C로 정상 종료합니다.
2. 안드로이드: `IeumOffice-Mobile-Android-preview`를 받아 압축을 풀고 안의 APK를 휴대폰에서 설치합니다.
   테스트용 디버그 서명이며 기기의 설치 정책을 따라야 합니다. Android 7.0 이상이 필요합니다.
3. 두 파일을 실행·설치하는 것만으로 문서가 자동 공유되지는 않습니다. 문서 서버 연결과 공유 설정은 별도입니다.
   PC 연결 안내는 `packages/cloud-documents/LOCAL.ko.md`, 각 패키지의 한국어 안내 파일에 있습니다.

윈도우 패키지는 런타임·문서 서버·편집 화면·의존성 라이선스를 포함합니다.
연결키나 사용자 문서는 포함하지 않습니다. 첫 실행 시 본인 PC에서 비공개 설정을 생성합니다.
실제 Windows GitHub runner에서 모바일 테스트 42개, 패키지의 Node 실행 파일을 이용한 시작·인증·문서 쓰기/읽기·외부 HTTP 도구 검사를 통과했습니다.
윈도우의 디렉터리 fsync 미지원 문제를 수정했으며, 파일 fsync와 교체 방식은 유지합니다.
POSIX와 동일한 갑작스러운 정전 내구성이나 윈도우 폴더 ACL을 대신 보장하지는 않습니다.

안드로이드는 Java 21·SDK 36에서 Drive 네이티브 브리지를 포함한 디버그 APK를 컴파일했습니다.
실기기의 한글 입력, 파일 공유, USB 연결, 백그라운드·강제 종료 복구는 검증 전입니다.
빌드마다 임시 디버그 서명이 달라질 수 있어, 재설치를 위해 기존 앱을 삭제하기 전에는 문서를 내보내야 합니다.

현재 편집 대상은 `.md`·`.txt`입니다. Google OAuth 설정, 공용 HTTPS 서버, 클라우드 Codex/ChatGPT 도구 설치는 아직 없습니다.
PC의 로컬 주소는 클라우드 Codex에서 직접 접근할 수 없습니다. 연결된 AI를 이 앱에서 자동으로 실행하지 않습니다.
